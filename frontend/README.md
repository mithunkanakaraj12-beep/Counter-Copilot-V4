# Frontend

**Proposed owner:** Claude 2.

Build a minimal responsive employee application:
1. Unified inbox/review queue.
2. One request review card with original source, transcript/parsed content, extracted materials, SKU evidence, inventory coverage/freshness, optional pricing, and warnings.
3. Edit, approve internal draft, decline, request clarification, assign, and notes.
4. Quote status and manual employee-initiated follow-up.
5. Secure authenticated notification link.

Avoid advanced analytics, full CRM, multi-branch reporting, and a large settings center in the first pilot. Approval is not quote send, ERP order, or inventory reservation.
